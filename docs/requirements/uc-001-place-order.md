## 1. 개요

로그인한 고객이 상품 하나 이상을 주문한다. 시스템은 주문을 기록하고 주문 항목 전체의 재고를 한꺼번에 예약한다. 모두 예약되면 주문을 확정하고, 하나라도 재고가 부족하면 거절하고, 정해진 시간 안에 결과를 얻지 못하면 실패로 처리한다. 결과와 관계없이 주문은 기록되고 조회할 수 있다. (P§0, OQ-002, OQ-006)

## 2. 액터

- **고객**: 로그인한 사용자. 상품과 수량을 정해 주문을 요청한다.

## 3. 사전 조건

- 고객이 로그인해 있다. (OQ-007)
- 주문할 상품의 재고가 초기 데이터로 들어 있다. (OQ-001)

## 4. 기본 흐름 — 주문 확정

1. 고객이 주문 항목(상품과 수량) 하나 이상과 주문 요청 키를 담아 주문을 요청한다. (OQ-006, OQ-008)
2. 시스템이 로그인한 고객을 확인하고 주문 항목을 검사한다(BR-009).
3. 시스템이 주문을 "처리중"으로 기록하고 주문 번호를 붙인다. (OQ-002)
4. 시스템이 주문 번호와 함께 주문 항목 전체의 재고를 한꺼번에 예약한다. (P§5-3, P§5-5)
5. 모두 예약되면 시스템이 주문을 "확정"으로 바꾼다. (P§5-6)
6. 시스템이 고객에게 주문 번호와 확정 결과를 돌려준다.

|---|---|---|---|
| A1 재고 부족 | 4단계에서 항목 하나라도 재고가 주문 수량보다 적다 | 어느 항목도 예약하지 않는다. 주문을 "거절"로 바꾸고, 고객에게 거절과 부족한 상품 목록을 돌려준다 | P§0, OQ-002, OQ-006 |
| A2 상품 없음 | 4단계에서 없는 상품이 있다 | A1과 같이 "거절"로 처리하고 사유를 "상품 없음"으로 둔다 | — |
| A3 일시 오류 | 4단계가 연결 실패, 시간 초과, 일시 오류로 실패한다 | 즉시, 1초, 2초, 4초, 8초 뒤에 최대 5번 다시 시도한다. 성공하면 5단계로 간다 | OQ-004 |
| A4 시간 안에 결과 없음 | 재시도를 포함해 30초 안에 예약 결과를 얻지 못한다 | 주문을 "실패"로 바꾸고 고객에게 "잠시 후 다시 시도"를 돌려준다. 그 뒤 예약 해제를 요청하고, 해제 결과를 주문에 기록한다 | P§6-②, OQ-002, OQ-004 |
| A5 재고 확인이 계속 실패하는 중 | 최근 재고 확인이 계속 실패해 시스템이 재고 확인을 잠시 멈춘 상태다 | 기다리지 않고 바로 주문을 "실패"로 바꾸고 "잠시 후 다시 시도"를 돌려준다. 예약 요청을 한 번도 보내지 않았으므로 해제도 하지 않는다 | OQ-009 |
| A6 예약 재요청 | 4단계의 결과를 받지 못해 같은 주문 번호로 예약을 다시 요청한다 | 재고는 한 번만 줄어든다. 처음과 같은 결과를 돌려준다 | P§6-①, OQ-005 |
| A7 같은 주문 요청 다시 보냄 | 고객이 같은 주문 요청 키로 다시 요청한다 | 새 주문을 만들지 않고, 이미 있는 주문의 현재 상태를 돌려준다. 키는 같은데 내용이 다르면 오류를 돌려준다 | OQ-008 |
| A8 로그인 안 됨 | 2단계에서 고객을 확인할 수 없다 | 주문을 기록하지 않고 거부한다 | OQ-007 |
| A9 주문 항목이 잘못됨 | 2단계에서 BR-009를 어긴다 | 주문을 기록하지 않고 오류를 돌려준다 | OQ-006 |

## 6. 업무 규칙

| ID | 규칙 | 출처 |
|---|---|---|

| BR-002 | 주문 항목 중 하나라도 재고가 부족하면 어느 항목도 예약하지 않고 주문 전체를 거절한다. 일부 항목만 확정하지 않는다 | P§0, OQ-006 |
| BR-003 | 재고 수량은 0보다 작아지지 않는다. 동시에 들어온 주문이 같은 재고를 두고 다퉈도 마찬가지다 | `[추론]` |
| BR-004 | 주문은 모든 항목의 재고 예약에 성공한 경우에만 "확정"이 된다 | P§0 |
| BR-005 | "거절"이나 "실패"로 끝난 주문 때문에 재고가 줄어든 채 남지 않는다. 예약 요청을 보낸 적이 있는 실패 주문은 예약 해제를 요청한다 | OQ-002 |
| BR-006 | 주문은 로그인한 고객 본인의 이름으로만 만든다 | OQ-007 |
| BR-007 | 고객이 확인되고 항목이 올바른 주문 요청은 결과와 관계없이 모두 기록한다 | OQ-002 |
| BR-008 | 같은 고객이 같은 주문 요청 키로 보낸 요청은 주문 하나가 된다. 새 주문은 새 키로 보낸다 | OQ-008 |
| BR-009 | 주문 항목은 1개 이상 20개 이하이고, 각 수량은 1 이상 99 이하이며, 같은 상품은 한 줄에만 나온다 | OQ-006, 2026-10-05 결정 |
