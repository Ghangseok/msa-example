# 아키텍처 규칙

- 상태: **확정 (2026-10-05)**
- 출처: P = [마이크로서비스와 쿠버네티스 기초](../references/msa-k8s-primer.md), [ADR-0001](../adr/0001-single-speckit-at-root.md)
- 쓰는 곳: `/speckit-constitution`의 입력, `/speckit-plan`의 Constitution Check. 헌법(`.specify/memory/constitution.md`)은 이 문서의 **반드시** 규칙을 원칙 8개로 묶고, 세부 규칙으로 이 문서를 가리킨다. 각 규칙이 어느 원칙에 속하는지는 표의 "헌법 원칙" 칸에 적는다.

모든 서비스에 공통인 규칙이다. 한 서비스에만 해당하는 규칙(패키지 구조, DB 스키마 규칙 등)은 `services/<svc>/CLAUDE.md`에 적는다.

수준: **반드시**는 어기면 리뷰에서 막는다. plan.md의 Complexity Tracking에 이유를 적어 넘길 수 없고, 바꾸려면 ADR을 쓰고 헌법을 개정한다. **권장**은 어길 때 plan.md의 Complexity Tracking에 이유를 적는다.

## 용어

- **마이크로서비스 (microservice)**: 업무 기능 하나를 맡아 따로 배포하고 따로 확장하는 작은 서비스다. 이 프로젝트에는 주문 서비스와 재고 서비스가 있다.
- **Pod**: 쿠버네티스가 컨테이너를 실행하는 가장 작은 단위다. 언제든 지워지고 새로 만들어지므로, 남아야 하는 데이터를 Pod 안에 두지 않는다.
- **사이드카 (sidecar)**: 주 컨테이너와 같은 Pod에서 로그 수집 같은 보조 일만 하는 컨테이너다. 사이드카일 때만 Pod에 컨테이너를 더 넣는다.
- **공통 라이브러리 (`libs/`)**: 여러 서비스가 함께 쓰는 코드를 두는 폴더다. 추적 설정 같은 기술 코드만 두고 업무 코드는 두지 않는다.
- **서비스 디스커버리 (service discovery)**: 호출할 서비스의 주소를 찾아내는 방법이다. 이 프로젝트는 별도 서버 없이 쿠버네티스 Service 이름으로 찾는다.
- **Eureka**: Spring Cloud가 제공하는 서비스 디스커버리 서버다. 쿠버네티스 Service로 충분해서 이 프로젝트에서는 쓰지 않는다.
- **연결 제한 시간 (connect timeout)**: 상대 서버와 연결을 맺을 때까지 기다리는 최대 시간이다. 코드에 적지 않고 설정값으로 둔다.
- **응답 제한 시간 (read timeout)**: 연결한 뒤 응답을 받을 때까지 기다리는 최대 시간이다. 코드에 적지 않고 설정값으로 둔다.
- **하드코딩 (hard-coding)**: 바뀔 수 있는 값을 설정이 아니라 코드에 직접 적는 것이다. 제한 시간, 주소, 비밀번호는 하드코딩하지 않는다.
- **멱등성 (idempotency)**: 같은 요청을 여러 번 받아도 결과가 한 번 받은 것과 같은 성질이다. 재고 예약은 주문 번호로, 주문 생성은 주문 요청 키로 같은 요청인지 알아본다.
- **멱등 키 (idempotency key)**: 받는 쪽이 같은 요청인지 알아보는 데 쓰는 값이다. 재고 예약의 멱등 키는 주문 번호이고, 주문 생성의 멱등 키는 주문 요청 키다.
- **계약 (contract)**: 서비스 사이 API와 이벤트의 형식을 적은 명세다. 이 저장소에서는 `contracts/`의 OpenAPI, AsyncAPI 파일이 계약이다.
- **OpenAPI**: HTTP API의 경로, 요청, 응답 형식을 적는 표준 명세 형식이다. 서비스 사이 API의 계약을 `contracts/`에 OpenAPI 파일로 둔다.
- **AsyncAPI**: 메시지 브로커로 주고받는 이벤트의 형식을 적는 표준 명세 형식이다. 이벤트를 쓰게 되면 `contracts/`에 AsyncAPI 파일로 둔다.
- **이벤트 (event)**: 한 서비스가 일어난 일을 알리려고 메시지 브로커에 올리는 메시지다. 지금 단계에서는 쓰지 않는다.
- **깨는 변경 (breaking change)**: 옛 버전의 호출하는 쪽이나 받는 쪽이 더는 동작하지 않게 만드는 변경이다. 필드 삭제, 필드 이름 변경, 새 상태 값 추가가 여기에 든다.
- **상태 값 (enum)**: 미리 정한 몇 개의 값 가운데 하나만 갖는 필드다. 주문 상태는 처리중, 확정, 거절, 실패 가운데 하나다.
- **재시도 (retry)**: 실패한 호출을 잠시 기다렸다가 다시 보내는 것이다. 이 프로젝트에서는 일시 오류에만, 최대 5번까지, 전체 30초 안에서 한다.
- **트랜잭션 (transaction)**: 여러 DB 변경을 한 묶음으로 처리해서, 모두 반영하거나 모두 되돌리는 단위다. 이 프로젝트는 원격 호출을 트랜잭션 밖에서 하고, 호출 앞뒤의 저장을 각각 따로 커밋한다.
- **서킷 브레이커 (circuit breaker)**: 상대 서비스 호출이 계속 실패하면 한동안 호출을 멈추고 바로 실패를 돌려주는 장치다. 재고 서비스가 멈췄을 때 주문 서비스까지 멈추지 않게 막는다.
- **동기 호출 (synchronous call)**: 요청을 보내고 응답이 올 때까지 기다리는 호출이다. 주문 서비스는 재고 예약을 동기 HTTP로 부른다.
- **가상 스레드 (virtual thread)**: Java 21부터 쓸 수 있는 가벼운 스레드로, 응답을 기다리는 동안 운영체제 스레드를 잡고 있지 않는다. 이 프로젝트는 Java 17이라 쓸 수 없어서, 서킷 브레이커로 스레드가 바닥나는 것을 막는다.
- **readiness 프로브 (readiness probe)**: 쿠버네티스가 Pod에 "요청을 받을 준비가 됐나"를 주기적으로 묻는 검사다. 실패하면 그 Pod에는 요청을 보내지 않는다.
- **liveness 프로브 (liveness probe)**: 쿠버네티스가 Pod에 "살아 있나"를 주기적으로 묻는 검사다. 정해진 횟수만큼 실패하면 컨테이너를 재시작한다.
- **Actuator**: Spring Boot가 health 같은 운영용 엔드포인트를 만들어 주는 모듈이다. readiness 프로브와 liveness 프로브가 이 엔드포인트를 부른다.
- **그레이스풀 셧다운 (graceful shutdown)**: 종료 신호를 받으면 새 요청은 받지 않고, 처리 중인 요청을 끝낸 뒤 종료하는 방식이다. 배포나 확장으로 Pod가 내려갈 때 요청이 끊기지 않게 한다.
- **terminationGracePeriodSeconds**: 쿠버네티스가 Pod에 종료 신호를 보낸 뒤 강제로 끝내기까지 기다리는 시간이다. 앱의 종료 대기 시간(35초)보다 긴 45초로 둔다.
- **ConfigMap, Secret**: 쿠버네티스가 환경마다 다른 값을 Pod에 넣어 주는 객체다. 일반 설정값은 ConfigMap에, 비밀번호 같은 값은 Secret에 둔다.
- **`.env` 파일 (environment file)**: 환경변수 값을 적어 두는 파일이다. `.gitignore`에 들어 있어 저장소에 올라가지 않고, 저장소에는 값을 비운 `.env.example`만 둔다.
- **replicas**: Deployment가 유지하는 Pod 수다. 서비스마다 2 이상으로 둬서 Pod 하나가 사라져도 서비스가 멈추지 않게 한다.
- **OpenTelemetry**: 추적, 로그, 메트릭을 모으고 보내는 방법을 정한 오픈소스 표준과 도구 모음이다. 두 서비스가 이것으로 관측 데이터를 보낸다.
- **OTLP (OpenTelemetry Protocol)**: OpenTelemetry가 관측 데이터를 저장소로 보낼 때 쓰는 전송 형식이다. 앱은 `lgtm:4318`로 OTLP를 보낸다.
- **추적 ID (trace ID)**: 요청 하나에 붙여 여러 서비스를 따라다니게 하는 번호다. 이 번호로 여러 서비스의 로그를 한곳에서 함께 찾는다.
- **`grafana/otel-lgtm`**: 로그(Loki), 추적(Tempo), 메트릭(Prometheus), 화면(Grafana)을 컨테이너 하나에 담은 개발용 관측 도구다. compose로 클러스터 밖에 띄워, Pod가 사라져도 기록이 남게 한다.
- **JWT (JSON Web Token)**: 로그인한 사용자 정보를 담고 서명한 토큰이다. 이 프로젝트에서는 Keycloak이 발급하고 주문 서비스가 검증한다.
- **`sub` (subject)**: JWT 안에서 사용자를 구별하는 값이다. 이 프로젝트에서는 이 값을 고객 ID로 쓴다.
- **OAuth2 리소스 서버 (OAuth2 Resource Server)**: 요청에 담긴 토큰을 검증하고 보호된 API를 내주는 서버의 역할이다. 주문 서비스가 Spring Security로 이 역할을 한다.
- **Keycloak**: 사용자 계정, 로그인, 토큰 발급을 맡는 오픈소스 인증 서버다. 이 프로젝트는 Keycloak을 직접 만들지 않고 가져다 쓰며, 계정은 초기 데이터로 넣는다.
- **ADR (Architecture Decision Record)**: 아키텍처 결정과 그 이유를 남기는 문서다. `docs/adr/`에 둔다.
- **헌법 (constitution)**: spec-kit의 모든 명령이 읽는 프로젝트 원칙 문서다. `.specify/memory/constitution.md` 파일이 헌법이다.
- **반드시 / 권장 (MUST / SHOULD)**: 규칙의 강도다. "반드시"는 예외 없이 지키고, "권장"은 이유를 적으면 어길 수 있다.
- **Complexity Tracking**: plan.md 안에서 권장 규칙을 어길 수밖에 없을 때 그 이유를 적는 절이다. "반드시" 규칙을 어긴 것은 여기에 적어 넘길 수 없다.
- **Constitution Check**: plan.md 안에서 plan이 헌법을 지키는지 확인하는 절이다. `docs/standards/architecture-rules.md`의 "반드시" 규칙을 하나씩 확인한다.
